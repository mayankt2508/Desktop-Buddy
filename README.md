# Desktop-Buddy🤖💙

An interactive **Desktop Buddy** inspired by Mochi-style companions, built using embedded systems and custom UI design.  
This project combines emotions, real-time information, and dashboard monitoring into a compact smart desk companion.

---

## ✨ Features

- 😊 Emotion-based animated expressions
- ⏰ Real-time Time display
- 📅 Day & Date display
- 🌍 Place/Location display
- 🌦️ Weather updates
- 📊 Dashboard for live stats and real-time data monitoring
- 🎨 Custom UI design
- 🖨️ Compact 3D-printed enclosure
- ⚡ Embedded system based implementation

---

## 🛠️ Tech Stack

### Hardware
- ESP-based microcontroller
- OLED Display
- Custom 3D Printed Case

### Software
- Arduino IDE
- Embedded C/C++
- Custom UI Graphics

---

## 🚀 Future Improvements

- Voice interaction
- AI-based responses
- Smart notifications
- Advanced animations
- Personalized emotions and interactions

---

## 🎯 Inspiration

This project was inspired by Mochi-style desktop companions and the idea of creating electronics that feel interactive, expressive, and human-like.
